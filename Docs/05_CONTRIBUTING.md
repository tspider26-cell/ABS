# CONTRIBUTING

## Zasady pracy

Projekt rozwijamy etapami.

Każda zmiana powinna:

- pozostawiać działającą aplikację,
- być opisana w DEVLOG,
- być zapisana w Git.

---

## Commit

Każdy commit powinien mieć krótki opis.

Przykłady:

- Initial project structure
- Camera preview
- Card detection
- Market module

---

## Kod

Kod powinien być:

- prosty,
- czytelny,
- dobrze podzielony na moduły.
