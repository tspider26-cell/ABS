# ROADMAP

## Cel projektu

Artysta Break Studio (ABS) to aplikacja wspierająca otwieranie kart Pokémon podczas transmisji na żywo.

Główne cele projektu:

- wyświetlanie obrazu z kamery,
- wykrywanie kart Pokémon,
- rozpoznawanie kart za pomocą AI,
- pobieranie aktualnych cen,
- wyświetlanie informacji jako overlay podczas transmisji,
- prowadzenie statystyk i archiwum otwieranych kart.
